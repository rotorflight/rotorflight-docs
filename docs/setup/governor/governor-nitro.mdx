# Governor Nitro Setup

The governor nitro feature allows you to control the motor speed based on the throttle input and other parameters. There are multiple ways to set up a governor for nitro. This will cover a complete governor setup specific for nitro.

## Motors page
Set ESC protocol to PWM
Enable RPM sensor
Set ESC update frequency to the rate of your servo. Usually 333hz.
Set endpoints of the servo with Motor stop and 100% throttle value
Set main gear ratio
Set tail gear ratio
Main motor pole count usually 2

#### Throttle type
There are multiple ways to set this. Easiest way is using function. With this mode you will only set the governor in a mode. Like Off, Idle, Auto and Run.
