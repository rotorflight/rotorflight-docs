# Keyboard Shortcuts

You can also find this list in the Explorer under the **?** button in the
toolbar. On a Mac, use the **⌥ Option** key wherever it says **Alt**.

!!! warning "SCREENSHOT NEEDED: shortcuts.png"
    The shortcuts list opened from the **?** button in the toolbar, with the ? button visible if possible.

## Mouse

| Action | Does |
| --- | --- |
| Wheel | Zooms the graph in and out around the pointer. Pinch on a trackpad. |
| **Shift**+wheel | Moves backwards and forwards through the log. Swipe sideways on a trackpad. |
| Drag | Moves the graph left and right. |
| Right-click | Opens a menu on the graph or seek bar. From it you can go to that time, set the start or end, add a marker or bookmark, zoom, or export. *New in 2.4.* |
| **Shift** over the Analyser | Shows the frequency under the pointer and its harmonics, in Hz and rpm. |

## Moving and playing

| Key | Does |
| --- | --- |
| **Space** | Plays or pauses the log, and the video if one is loaded. |
| **Home**, **End** | Goes to the start or end of the log. |
| **←**, **→** | Moves back or forward 100 ms. |
| **Alt**+**←**, **Alt**+**→** | Moves one frame. If a video is loaded this is one video frame, otherwise one log frame. |
| **PgUp**, **PgDn** | Moves back or forward quickly. |
| **Shift**+**←**, **Shift**+**→** | Zooms out or in. |
| **Shift**+**Alt**+**←**, **Shift**+**Alt**+**→** | Zooms out or in, faster. |

## Views

| Key | Does |
| --- | --- |
| **H** | Shows or hides the log header. |
| **T** | Shows or hides the values table. |
| **A** | Shows or hides the Analyser. |
| **C** | Shows or hides the CLI dump, if one is loaded. |
| **Z** | Zooms all the way out, and back. |
| **S** | Turns all graph smoothing off, and back on. |
| **X** | Turns expo off on all traces, and back on. |
| **G** | Hides all grids, and shows them again. |

## Marking

| Key | Does |
| --- | --- |
| **I**, **O** | Sets the start or end of the stretch used by the Analyser, Step Response and video export. |
| **M** | Adds or removes a marker. The toolbar then shows how far you are from it. |
| **Alt**+**M** | Smart Sync. Syncs the video to the log at the marker. See [Smart Sync](video-and-export.md#smart-sync). |
| **Alt**+**Shift**+**1** to **9** | Saves the current time as bookmark 1 to 9. |
| **Alt**+**1** to **9** | Jumps to bookmark 1 to 9. |
| **Alt**+**Shift**+**0** | Clears all bookmarks. |

## Workspaces and graphs

| Key | Does |
| --- | --- |
| **Shift**+**0** to **9** | Saves the current graphs to workspace 0 to 9. |
| **0** to **9** | Loads workspace 0 to 9. |
| **Ctrl**+**Z** | Goes back to the previous graph layout. Press again to return. |
| **Alt**+**S** | Saves the graph as a PNG image. |
| **Ctrl**+wheel over a trace in the legend | Changes that trace's smoothing. |
| **Shift**+wheel over a trace in the legend | Changes that trace's zoom. |
| **Alt**+wheel over a trace in the legend | Changes that trace's expo. |
