# Contributing

Rotorflight is an open-source community project. You don't have to be a
programmer to help -- most of what keeps the project going is pilots helping
pilots.

## Ways to help

- **Help other pilots** on the [Rotorflight Discord](https://discord.gg/FyfMF4RwSA)
  and forums.
- **Report bugs** -- with steps to reproduce them, a `diff all` and a Blackbox
  log where relevant -- on the issue tracker of the right repository on
  [GitHub](https://github.com/rotorflight). The issue trackers aren't for
  support questions; ask on Discord first.
- **Test** development snapshots and release candidates, and report back.
- **Improve these docs** -- see [Editing the Docs](editing-the-docs.md).
- **Translate** the Configurator and the Lua suites into your language.
- **Write code** for the firmware, Configurator, Blackbox Explorer or Lua
  suites -- see [Developers](developers.md).
- **Support the project** financially -- see [Support the Project](support.md).

## Flight testing

Testing new code is how Rotorflight gets better -- and bugs, or a
misconfiguration, do happen.

!!! danger "Crashes are part of testing"
    Anyone testing development code must accept that crashing is possible.

Testers who help most have:

- a spare collective-pitch helicopter;
- good building skills, especially with electronics;
- enough flying skill to tell whether something works;
- patience, and the habit of recording Blackbox logs.
