# DIY Projects

These guides cover adapting Betaflight flight controllers for helicopters
and building accessories for Rotorflight installations.

## Flight controller conversions

- [Betaflight FC (DIY)](betaflight-diy.md): flashing and adapting a drone
  flight controller, with an OMPHobby M1 / DarwinFPV 15A build example,
  wiring, resource mappings and a downloadable configuration.
- [Remapping Outputs](../setup/remapping.md): assigning pads to servos,
  motors and RPM inputs.
- [Sensitive gyros](betaflight-diy.md#sensitive-gyros): soft-mounting a
  board with an MPU-6500 gyro.
- [BLHeli_S to Bluejay](../setup/blheli-s-to-bluejay.md): flashing ESCs
  for bidirectional DShot RPM feedback.

## Accessories

- [Castle telemetry adapter](../setup/esc-telemetry.md#castle-creations):
  adding a pull-up resistor for Castle Link Live telemetry.
- [LED lighting](../setup/led-strip.md): wiring and configuring scale
  lights, including a [PicoBlade LED bus](../setup/led-strip.md#a-picoblade-led-bus).
- [OpenLager Logging](../setup/openlager.md): wiring and setting up an
  external Blackbox logger.
